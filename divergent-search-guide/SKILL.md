# Divergent Search & Reconnaissance Guide

启发式发散思维导引协议，辅助进行高穿透度、低额度消耗的多维信息检索与技术/服务调研。**非强制性拦截，仅作发散思维指引**。

## 1. 核心发散四步循环 (The 4-Step Divergent Loop)

```
[原始模糊需求]
       │
       ▼
 1. 意图解构 ──► 拆解为4个核心受力面：渠道平台 / 支付摩擦 / 合规门槛 / 替代方案
       │
       ▼
 2. 社区穿透 ──► 优先检索实操论坛 (site:v2ex.com / site:nodeseek.com / site:linux.do / site:reddit.com)
       │        获取一线老玩家真实踩坑、黑名单与最新风控规则
       ▼
 3. 多分支发散 ─► 提取Step 2发现的黑话/关键词，分头直搜官方文档、技术评测与竞品对比
       │
       ▼
 4. 时效核验 ──► 强制校验 2026 最新时效（汇率、KYC政策、实名变动、优惠失效）
```

## 2. 启发式发散思维检查清单 (Heuristic Checklist)

当面对未知流程或复杂调研（如“国外域名申请”、“海外VPS选购”、“开源选型对比”）时，主动发散自检：
- **渠道发散**：不仅搜“怎么买”，还搜“在哪买最稳”与“哪个平台跑路/风控严”；
- **支付与风控发散**：不仅看价格，查是否需要国内卡/外币卡/PayPal/Crypto，是否需要强制验证手机或传身份证；
- **隐形门槛发散**：是否有续费刺客（首年便宜次年翻倍）、是否自带免费隐私保护（WHOIS Privacy）、是否易被墙；
- **社区黑话与共识**：搜索关键词追加论坛专有术语（如 `nodeseek 避坑`, `v2ex 体验`, `reddit review`）。
