## 二、 阶段实战指南与技能联动矩阵

### 1. 个人电脑深度维护与性能调优
* **核心目标**：融合 Sysinternals 等 40 款顶级兵器，维护系统极速响应与存储纯净。
* **SOP 规范**：
  - 核心红线：保护 `RemotePC_Service`（华为远程）与 `lmgrd.exe`（SolidWorks 许可）；
  - 垃圾清理：仅限 `$env:TEMP` / `CrashDumps` / `INetCache` 等临时缓存；
  - 桌面零入侵：严禁未经允许向用户桌面生成快捷方式或文件。
* **【联动技能】**：[`pc-maintenance-master`](../../pc-maintenance-master/SKILL.md)
  - *触发示例*：“帮我全面体检一下电脑状态和内存占用”、“安全清理系统临时垃圾”。

### 2. 全盘秒搜与芯片手册文献调阅
* **核心目标**：在毫秒级穿透全盘数十万工程文件，并检索 Zotero 本地文献库。
* **SOP 规范**：只读调阅 `zotero.sqlite`，利用 voidtools 极速提取代码、零件与 Datasheet。
* **【联动技能】**：[`everything-search`](../../everything-search/SKILL.md)、[`zotero-assistant`](../../zotero-assistant/SKILL.md)
  - *触发示例*：“帮我搜一下电脑里所有的 .ioc 工程”、“查一下我 Zotero 里的 STM32F4 芯片手册”。

### 3. 高校比赛物料发票报销与 11 列总账
* **核心目标**：严格对标高校财务处报销规范，实现单据识别、查重、动态凑单与总账生成。
* **财务硬核三要素（红线）**：
  1. 抬头：完全匹配 **`武汉轻工大学`**；
  2. 税号：完全匹配 **`124200004416255673`**；
  3. 面额上限：**单张发票价税合计不得超过 500.00 元**（超额必须拆票）。
* **凑单与防重规约**：
  - 大额优先：优先提取大额拆票物料，动态逼近预算目标；
  - 就地加锁：源物料目录在抽调时强制原地追加 `_已提交` 锁，只准复制严禁剪切；
  - 专包架构：专包划分为 `1.物料与发票/` 与 `2.按金额排序发票PDF/`，发票原件强制二进制原生保真（严禁光栅化）。
* **【联动技能】**：[`invoice-audit-master`](../../invoice-audit-master/SKILL.md)
  - *触发示例*：“审计一下这个批次里的所有发票合规性与税号”、“凑一个两万元左右的报销单并生成总账”。

### 4. Git 研发日报与周报自动化生成
* **核心目标**：从底层 Git 提交与代码 Diff 中提炼出条理清晰的高管级工程日报/周报。
* **【联动技能】**：[`git-worklog-reporter`](../../git-worklog-reporter/SKILL.md)
  - *触发示例*：“根据我今天的 git 提交写一份今日研发日报”、“整理我过去 7 天的代码修改生成一份结构化周报”。

### 5. 启发式发散搜索与多维信息调研
* **核心目标**：针对未知网络服务、国外域名/VPS 申请流程、开源生态对比，通过发散思维与社区一线穿透获取真实信息，规避单一搜索盲区与大量 Token 额度消耗。
* **4 步发散循环**：意图解构（平台/支付/合规/替代） ➔ 社区穿透（V2EX / NodeSeek / Reddit） ➔ 多分支发散 ➔ 2026时效校验。
* **【联动技能】**：[`divergent-search-guide`](../../divergent-search-guide/SKILL.md)
  - *触发示例*：“帮我查一下怎么申请一个国外域名，包括主流平台对比、支付方式与避坑建议”、“调研一下目前海外免实名 VPS 选购方案与社区评价”。

## 三、 实战踩坑手记与经验增量池 (Hard-Won Knowledge)

1. **发票光栅化防伪拒收**：严禁将矢量 PDF 转为图片后再合并成 PDF，会导致税局印章失真退单；
2. **财务隐私绝对隔离**：发票数据、对账明细与个人资产严禁纳入 Git 仓库，必须在 `.gitignore` 彻底屏蔽；
3. **报销状态封顶**：自动抽调与归档的状态机最高止步于 `_已提交`，绝不擅自标记为 `_已核销`（必须待财务实际打款后由人工确认升级）。
